# ZeroKore Skills

Project-local Codebuff skills live here: `.codebuff/skills/`

## Adding a skill

1. **Markdown skill**: create a folder matching the skill name and drop the `.md` inside:

   ```
   .codebuff/skills/my-skill/my-skill.md
   ```

2. **Zip skill**: unzip it first, then copy the extracted folder here. Keep the original zip outside the repo (e.g. `~/Downloads/skills-archive/`) as a backup.

## Tips

- One folder per skill; the `.md` file name should match the folder name.
- These files are committed with the repo, so anyone working on ZeroKore gets them.
- For skills you want in *every* project, put them in `~/.codebuff/skills/` on your own machine instead.
